# Mobile baking

Open an NXSG graph with the material used by your avatar, then click **Bake for Mobile** beside **Build for VRChat**. NXSG captures the connected albedo, emission, normal, metallic, roughness and occlusion branches at the moment you click, compositing their textures, UV effects, colors, material overrides, and time-driven effects into 1024 px textures. Texture overrides are matched to their graph resource when a branch is isolated, even if its shader property name changes. The current Preview AudioLink value is used when that preview is enabled. NXSG creates a separate material using the VRChat SDK's `VRChat/Mobile/Toon Standard` shader. The desktop graph and material remain intact.

If the surface has no connected albedo input, the mobile bake uses opaque black for albedo. It writes a small 1×1 black texture; the other connected branches can still bake.

The baked assets live under `Assets/NXSGGenerated/<graph GUID>/Mobile/<material GUID>/`. NXSG records the desktop/mobile material pair in `Assets/NXSGGenerated/MobileBakes.asset`. When Unity's active build target changes to Android, NXSG replaces matching **open-scene renderer slots** with the mobile material. Switching back to a desktop target restores the desktop material. It also syncs when a scene opens or an avatar is added to an open scene. Save the scene after the swap before uploading that platform's avatar.

The snapshot uses a flat preview plane with mesh UV0, a front-facing camera, and a fixed sample time. The maps include every texture and effect connected to those six branches, but any view-, mesh-, world-, light-, or live-AudioLink-dependent effect is only a sample of that preview plane. LTCGI passes through its connected input color without world lighting; if it has no input color, it contributes black. Its appearance can differ across an avatar's curved geometry or at another time. The mobile material is opaque: NXSG forces baked albedo alpha to 1, ignores desktop opacity and cutout controls, and reports that approximation. Displacement geometry is omitted and reported. Surface Particles and other geometry effects are omitted while their base surface is baked. Other surface controls, fur and special lighting are not represented by this mobile material. Inspect the generated mobile material and avatar in Unity before upload.

Rebake after changing the graph or source material. The generated mobile material is a snapshot; changing the desktop graph alone does not update its texture. The automatic swap acts on renderers in open scenes, not on prefab assets on disk. VRChat still needs its normal Android avatar upload for mobile users to see that version.
