# NXSG 0.1.0-alpha.23

Surface Particles now has **Edge sharpness**, with a slider and a float input socket. Use 0 for the existing soft puff or 1 for a crisp circle.

Update the package, open the graph, select Surface Particles, and rebuild the shader after adjusting the control. Older graphs keep their soft edges.

Opacity and lifetime fading remain independent. This release does not change mirror alpha blending.
