# NXSG 0.1.0-alpha.2

A quality and usability release for the Linux-tested Unity 2022.3.22f1 editor.

- Compact menus and a resizable Inspector / Nodes / Problems sidebar.
- Editable Float/Color parameters with stable shader references for animation.
- Retained sliders, synchronized numeric fields, undo routing and layoutless graph framing fixes.
- Correct tangent data in shadow passes; explicit warnings for unsupported screen-dependent shadows and additional pixel lights.
- Antialiased scanlines and three reproducible material studies: hologram, pearl and warm fur.
- Quick start, compatibility matrix, fresh editor imagery, rendered gallery and animation.
- Portable and packaging CI plus dirty-package release protection.

Validated with portable tests, five packaging tests and isolated Linux Unity editor/render checks. This remains an alpha: Windows/D3D, headset/stereo, live VRChat and integration acceptance are pending. No ForwardAdd support yet. License selection is pending.

Install through https://nerdrx.github.io/nxsg/ with prerelease packages enabled.
