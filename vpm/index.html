Manual install

If the button does not open your package manager, add this repository URL:

https://nerdrx.github.io/nxsg/index.json

  1. In Creator Companion, open Settings → Packages → Add Repository and paste the URL.
  2. Enable Show Pre-Release Packages. NXSG currently ships as 0.1.0-alpha.4.
  3. Manage your Unity project and add NX Shader Graph.
  4. In Unity, choose Tools → NXSG → Open Graph Editor. Open a graph or choose New.

On Linux, use a VPM-compatible manager's repository settings with the same URL. The VCC button needs a registered vcc:// handler.

Before you start

Developed and tested on Linux with Unity 2022.3.22f1, for PC Built-In shaders. Windows/D3D, headset stereo and VRChat client acceptance remain unverified. Start in a test project.

Import Example Graphs from NXSG's entry in Unity's Package Manager, or copy graphs from its Samples~ directory into Assets.
